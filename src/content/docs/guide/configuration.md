# 配置说明

本页用于记录每项配置的作用、可选值、默认值和生效条件。

## 运行模式

说明安静、均衡、性能、极速等模式的实际行为，以及设备不支持某个模式时的表现。

## 散热与性能

记录风扇策略、温度信息、性能参数的来源和限制。涉及风险的设置应给出清晰警告。

## 电源管理

说明充电上限、电源状态和适配器检测等功能。注明设置是否会持久化，以及何时恢复默认值。

## 灯光与显示

记录亮度、灯效、刷新率和显卡连接方式等设置的支持条件。

## 配置保存位置

在这里说明配置文件或系统设置的实际位置、格式与备份方法。如无用户可编辑的配置文件，可删除本节。
