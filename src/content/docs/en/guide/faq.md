# Frequently asked questions

Collect recurring questions here. Answers should include actionable checks, not only an explanation of the cause.

## Which devices does PredatorLite support?

List verified device families and explain how users can assess compatibility. Do not describe untested devices as supported.

## Why are some settings unavailable?

Explain how device capabilities, driver versions, system permissions, and power state can affect availability.

## Why was my configuration not saved?

Document when settings are stored, where they are stored, and which permission or file problems can block writes.

## How do I collect diagnostic information?

Describe log locations, required system information, and any private data users should remove before submitting a report.

## How do I report an issue?

Add the issue tracker URL in `src/site.ts`, then replace this text with the real reporting process.
